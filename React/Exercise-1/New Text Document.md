**1) Define SPA and its Benefits ?** 

**A)** It is a web application that loads a single HTML page ad dynamically updates the content without reloading entire page.

&#x09;**Benefits:**

&#x09;	**->** Better performance

&#x09;	**->** Easy Integration

&#x09;	**->** Faster page navigation

&#x09;	**->** Reduces server requests



**2) Define React and identify its working ?**

**A)** It is a open source JavaScript library developed by Facebook for building fast and interactive user interfaces using reusable components.

&#x09;**Working:**

&#x09;	**->** React creates virtual DOM

&#x09;	**->** when data changes react creates new virtual DOM

&#x09;	**->** React compares new virtual DOM with previous one

&#x09;	**->** Only the changed part is updated 

&#x09;	**->** Browser renders updated UI efficiently



**3) Identity difference between MPA and SPA ?** 

**A) SPA:** 

&#x09;**->** Single Page Application

&#x09;**->** no page reloads

&#x09;**->** fewer server requests

&#x09;**->** faster after initial load

&#x20;  **MPA:**

&#x09;**->** Multi Page Application

&#x09;**->** page reloads for every action

&#x09;**->** more server requests

&#x09;**->** slower due to page reloads



**4) Explain Props and Cons of SPA ?**

**A) Props:** 

&#x09;**->** Fast Navigation

&#x09;**->** Better User experiences

&#x09;**->** Less Bandwidth usage

&#x09;**->** Easy API integration

&#x09;**->** Responsive UI

&#x20;  **Cons:**

&#x09;**->** Longer initial loading time

&#x09;**->** JavaScript must be enabled

&#x09;**->** More memory usage on the client

&#x09;**->** Browser history management can require additional routing logic



**5) Explain about React ?**

**A)** 	**->** React is a JavaScript library used to build interactive and dynamic user interfaces. 

&#x09;**->** It follows a component-based architecture, allowing developers to create reusable UI components. 

&#x09;**->** React uses a Virtual DOM to improve performance by updating only the changed parts of the webpage. 

&#x09;**->** It supports one-way data binding, making data flow predictable and applications easier to maintain.



&#x09;**Main Characteristics :**

&#x09;	**->** Component-based architecture

&#x09;	**->** Virtual DOM

&#x09;	**->** JSX

&#x09;	**->** One-way data binding

&#x09;	**->** Reusable components

&#x09;	**->** High performance

&#x09;	**->** Easy integration with APIs



**6) Define Virtual DOM ?**

**A)** The Virtual DOM (Document Object Model) is a lightweight, in-memory copy of the real DOM maintained by React.



**7) Explain Features of React ?**

**A) 	Component-Based Architecture** – Build applications using reusable components.

&#x09;**Virtual DOM** – Updates only changed elements, improving performance.

&#x09;**JSX (JavaScript XML)** – Write HTML-like syntax inside JavaScript.

&#x09;**One-Way Data Binding** – Data flows from parent to child, making applications predictable.

&#x09;**Reusable Components** – Write once and reuse across the application.

&#x09;**High Performance** – Virtual DOM minimizes expensive DOM operations.

&#x09;**Declarative UI** – Describe how the UI should look based on the current state.

&#x09;**State Management** – Supports dynamic and interactive user interfaces.

&#x09;**Hooks** – Enable state and lifecycle features in functional components.

&#x09;**Cross-Platform Development** – React Native allows building mobile applications using React concepts.
